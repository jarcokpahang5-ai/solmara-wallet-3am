A hardware wallet's own excuse for refusing to sign a transaction at 3 AM: its secure element is off the clock, its private keys are in their pyjamas, and no gas fee bribes it before sunrise. Pure Python 3 standard library, deterministic, no network.

## Run it

```sh
python3 main.py
```
